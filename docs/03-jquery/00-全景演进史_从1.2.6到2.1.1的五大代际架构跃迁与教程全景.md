## 战场核心世界观：从“石器时代小石斧”到“现代工业重巡洋舰”

很多开发者以为 jQuery 从第一天起就是现在这个样子。  
**大错特错！** 在长达近十年的演进中，jQuery 经历了一次又一次**脱胎换骨式的架构重写**：
- 在 1.2.6 时代，它只是一个没有 Sizzle、没有 Deferred、没有 Callbacks 的 9 文件轻量级脚本；
- 到了 1.6.1 时代，它完成了模块化拆分与 `attr` vs `prop` 的世纪大分流；
- 到了 1.7 时代，它抽象出了观察者通用发动机 `$.Callbacks`，并用 `on()` 统一了长达数年的事件监听诸侯割据；
- 到了 2.x 时代，它毅然决然地斩断了 IE 6/7/8 的历史枷锁，代码体积断崖式下降，数据缓存系统完成双轨制升级！

```
┌────────────────────────────────────────────────────────────────────────┐
│                   jQuery 架构代际演进五大里程碑全景                     │
└────────────────────────────────────────────────────────────────────────┘

  【1.2.6 青铜时代 (2008)】
  ├── 仅 9 个单体文件，基于简单正则的 selector.js，无 Sizzle，无 Deferred
  └── 事件直接操作，数据直接挂在 DOM 自身，极其容易内存泄漏

  【1.6.1 白银时代 (2011)】
  ├── 模块彻底拆分出 manipulation / traversing / attributes / support
  ├── Sizzle 引擎正式独立引入！选择器性能提升数十倍
  ├── attr vs prop 世纪大分流 (特性与属性彻底解耦)
  └── 引入早期版本 Deferred (期约机制萌芽)

  【1.7 黄金时代 (2011底)】
  ├── 诞生了全库观察者统一底座：$.Callbacks！
  ├── Deferred 彻底重构为元组数据驱动 (Tuples Architecture)
  └── 事件体系大一统：引入 on() / off()，宣告 bind/live/delegate 时代终结！

  【2.0.3 王者时代 (2013)】
  ├── 彻底砍掉 IE 6/7/8 的几千行兼容性补丁 (attachEvent/ActiveXObject/VML)
  ├── 引入面向对象 Data 类，实现 dataUser 与 dataPriv 双轨物理隔离！
  └── 本仓库独家收录：名师全量注释精读版！

  【2.1.1 星耀时代 (2014)】
  └── 全面拥抱 AMD 模块化按需加载构建体系 (src/ 目录彻底模块工程化)
```

## 第一战：五大版本源码差异深度横向技术对比

### 1. `1.2.6/`（青铜初期版，9 个文件）
- **文件清单**：`intro.js`, `core.js`, `selector.js`, `event.js`, `ajax.js`, `fx.js`, `offset.js`, `dimensions.js`, `outro.js`。
- **架构特征**：
  1. **没有 Sizzle**：选择器用的是朴素的正则表达式和从左到右匹配，遇到复杂层级选择器时性能断崖式下跌；
  2. **没有 `$.Callbacks` 与 `$.Deferred`**：异步调用依然是原始的 success/error 回调参数嵌套；
  3. **数据直接挂载在 DOM 上**：`elem[expando] = data`，在 IE 下引发严重的内存泄漏风险。
- **研读价值**：阅读 1.2.6 能够看到 jQuery 最本真、最纯粹的无 `new` 工厂与原型环闭环原型，是理解架构雏形的极佳读物。

### 2. `1.6.1/`（白银重构版）
- **架构大事件**：
  1. **Sizzle 引擎正式入驻**：选择器模块独立为 `sizzle-jquery.js`，引入从右向左逆向解析与编译匹配算法；
  2. **`attr` 与 `prop` 世纪大分流**：
     - 在 1.6 之前，`attr` 和 `prop` 混为一谈，导致获取复选框 `checked` 状态时，有时返回 `"checked"` 有时返回 `true`；
     - 1.6.1 正式明确了 **Attribute（HTML 标签属性，字符串）** 与 **Property（DOM 对象属性，JS 真实值）** 的边界；
  3. **模块大解耦**：将 DOM 操作拆解为 `manipulation.js`，节点关系拆解为 `traversing.js`，浏览器特性嗅探拆解为 `support.js`。

### 3. `1.7/`（黄金大一统版）
- **架构大事件**：
  1. **`callbacks.js` 降临**：全库最强观察者调度中心诞生！通过四大旗标（`once`, `memory`, `unique`, `stopOnFalse`）为 `Deferred` 和事件系统提供了统一的底层轮子；
  2. **事件大一统 `on()` 与 `off()`**：
     - 在 1.7 之前，社区被 `bind`（直接绑定）、`live`（挂在 document 上的事件委托，性能极差）、`delegate`（局部委托）搞得晕头转向；
     - 1.7 用一个 `on(types, selector, data, fn)` 将直接绑定与事件委托完美统一，彻底废弃了性能低下的 `live`！

### 4. `2.0.3/`（现代精简版，带全量注释）
- **架构大事件**：
  1. **告别 IE 6/7/8 枷锁**：彻底移除 `document.attachEvent`、`filters` 滤镜、COM 兼容层，源码体积骤降 15% 以上；
  2. **`Data` 缓存系统双轨制**：由全局哈希表升级为 `Data` 类实例，划分 `dataUser` 与 `dataPriv`，内部事件与外部业务数据物理隔离；
  3. **本仓库核心资产**：本目录下的 `Core.js`, `Sizzle-annotation.js`, `Deferred.js`, `Callbacks.js`, `Event.js` 带有极其详尽的中文逐行源码注释，是学习 jQuery 最硬核的参考书。

### 5. `2.1.1/`（现代工程化版）
- **架构大事件**：
  - 源码全面按 AMD 规范拆分为 24 个独立小文件（`src/` 目录下），支持使用 RequireJS 或自动化构建工具进行**定制裁剪打包**（例如不需要动画或 Ajax 的用户可以自由排除模块）。
