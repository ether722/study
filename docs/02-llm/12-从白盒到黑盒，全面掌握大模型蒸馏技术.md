# 12-老带新传功秘籍：从白盒到黑盒的大模型蒸馏技术

> **【召唤师峡谷全局战术简报】**  
> 拥有 70B、405B 参数的超级模型就像退役的传奇冠军老将（Teacher）：大局观与团战意识天下无敌，但出场费极其高昂，单局推理动辄需要 8 张 H100 显卡，根本无法塞进平民手机或单张显卡中！  
> 如何让一个 0.1B~3B 的年轻替补新秀（Student）继承冠军老将的毕生绝学？答案就是**【知识蒸馏（Knowledge Distillation）】**！  
> 本篇彻底解构两大传功流派：  
> 1. **白盒蒸馏（手把手传授微操内功）**：学生模型对齐老将未失真的软标签分布（Soft Targets），用温度系数 $T$ 与 KL 散度萃取暗知识；  
> 2. **黑盒蒸馏（DeepSeek-R1 推理慢思考轨迹复刻）**：老将只输出思考链 `<think>...</think><answer>...</answer>`，小模型通过 10 倍权重重罚状态转换标记，完美复制老将的深度推理心智！

## 一、白盒蒸馏：萃取老将的软标签暗知识（Dark Knowledge）

在普通的 SFT 监督训练中，模型学习的是非黑即白的硬标签（One-Hot Ground Truth，如当前词是“回城”，概率为 1，其余所有词为 0）。  
但这会彻底丢失老将的“大局观”！例如当前局势下：
- “回城”概率 60%
- “控符”概率 35%
- “冲塔”概率 0.0001%

**“控符”的这 35% 概率，包含了极高价值的次优战术相关性（暗知识）！**

### 1. 温度平滑与 KL 散度损失公式
通过温度超参 $T$（Temperature）将老将与新秀的输出 Logits 变得更加平缓柔和：
$$
p_t = \text{Softmax}\left(\frac{z_t}{T}\right), \quad p_s = \text{Softmax}\left(\frac{z_s}{T}\right)
$$
蒸馏损失直接衡量新秀分布与老将分布的 KL 散度差距：
$$
\mathcal{L}_{\text{KD}} = T^2 \cdot \text{KL}(p_t \,||\, p_s)
$$
融合原生硬标签交叉熵的总损失：
$$
\mathcal{L}_{\text{Total}} = \alpha \cdot \mathcal{L}_{\text{CE}} + (1 - \alpha) \cdot \mathcal{L}_{\text{KD}}
$$

> **【战术细节：为什么公式前必须乘以 $T^2$？】**  
> 因为在将 logits 除以 $T$ 后，Softmax 的导数直接缩小了 $\frac{1}{T^2}$。为了确保蒸馏损失回传的梯度量级与硬标签 $\mathcal{L}_{\text{CE}}$ 保持在同一数量级，必须在最前面乘以 $T^2$ 作为梯度能量补偿！

```python
import torch
import torch.nn.functional as F

def distillation_loss_fn(student_logits, teacher_logits, temperature=1.0, reduction='batchmean'):
    """
    【老将传功损失函数】：KL 散度软标签对齐
    """
    # 1. 计算老将的平滑软标签（断开老将梯度）
    with torch.no_grad():
        teacher_probs = F.softmax(teacher_logits / temperature, dim=-1).detach()

    # 2. 计算新秀的对数概率
    student_log_probs = F.log_softmax(student_logits / temperature, dim=-1)

    # 3. 计算 KL 散度差距
    kl = F.kl_div(student_log_probs, teacher_probs, reduction=reduction)

    # 4. 温度梯度补偿
    return (temperature ** 2) * kl
```

## 二、白盒双模并进训练循环：老带新现场教学

```python
# 教师老将（深层大模型）与学生新秀（浅层轻装小模型）
lm_config_student = MiniMindConfig(hidden_size=512, num_hidden_layers=8)
lm_config_teacher = MiniMindConfig(hidden_size=768, num_hidden_layers=16)

def train_distill_epoch(model, teacher_model, train_loader, optimizer, scaler, alpha=0.5, temperature=2.0):
    teacher_model.eval()
    teacher_model.requires_grad_(False)  # 老将锁死参数，仅做场外指导

    for step, (X, Y, loss_mask) in enumerate(train_loader):
        X, Y, loss_mask = X.to(args.device), Y.to(args.device), loss_mask.to(args.device)
        loss_mask_flat = loss_mask.view(-1)

        with ctx:
            # 1. 新秀前向推导
            student_logits = model(X).logits

            # 2. 老将前向推导（零梯度）
            with torch.no_grad():
                teacher_logits = teacher_model(X).logits
                # 若新老模型词表有差异，截断对齐
                teacher_logits = teacher_logits[..., :student_logits.size(-1)]

            # 3. 标准硬标签损失（对齐真实答案）
            ce_loss = F.cross_entropy(
                student_logits.view(-1, student_logits.size(-1)),
                Y.view(-1),
                reduction='none'
            )
            ce_loss = (ce_loss * loss_mask_flat).sum() / (loss_mask_flat.sum() + 1e-8)

            # 4. 软标签蒸馏损失（向老将偷师）
            valid_mask = (loss_mask_flat == 1)
            distill_loss = distillation_loss_fn(
                student_logits.view(-1, student_logits.size(-1))[valid_mask],
                teacher_logits.view(-1, teacher_logits.size(-1))[valid_mask],
                temperature=temperature
            )

            # 5. 双重加权总损失
            loss = (alpha * ce_loss + (1 - alpha) * distill_loss) / args.accumulation_steps

        scaler.scale(loss).backward()
        if (step + 1) % args.accumulation_steps == 0:
            scaler.unscale_(optimizer)
            torch.nn.utils.clip_grad_norm_(model.parameters(), args.grad_clip)
            scaler.step(optimizer)
            scaler.update()
            optimizer.zero_grad(set_to_none=True)
```

## 三、黑盒蒸馏：DeepSeek-R1 慢思考思维链（CoT）复刻

很多时候，行业顶尖模型（如 GPT-4、Claude 3.5、DeepSeek-R1）只提供黑盒 API，根本不会把底层的未量化 Logits 吐给你。  
**黑盒蒸馏的破局之道：让老将把整套【慢动作战术思考推演（Chain-of-Thought）】全部写在公屏上！**

```json
{
    "conversations": [
        {"role": "user", "content": "前期劣势路被敌方双人组压在塔下，该如何破局？"},
        {"role": "assistant", "content": "<think>\n首先评估当前兵线态势。敌方控线在河道，如果我强行补刀会被击杀。\n方案一：呼叫中单反蹲，但中单正在吃线无法支援。\n方案二：放弃第一波远端近战兵，退回防御塔经验区，同时拉野怪入塔消耗兵线。\n结论：方案二阵亡风险最低，稳健保住经验等级。\n</think>\n<answer>\n稳守塔下吃经验，不要脸探补残血刀；利用野怪拉线重置小兵碰撞点，等待防御塔击杀小兵控回兵线。</answer>"}
```

### 【黑盒战备关键军规：关键状态转换 Token 赋予 10 倍暴击惩罚】
在训练小模型模仿思考链时，最容易翻车的是：小模型思考到一半突然忘了闭合 `</think>`，或者直接跳过 `<think>` 开始胡言乱语！  
**解法：在损失掩码中，一旦遇到 `<think>`、`</think>`、`<answer>`、`</answer>` 这 4 个状态机枢纽，将其 Loss Mask 权重直接乘以 10 倍！**

```python
# 识别思考链状态机边界 Token
think_boundary_ids = (
    tokenizer('<think>').input_ids +
    tokenizer('</think>').input_ids +
    tokenizer('<answer>').input_ids +
    tokenizer('</answer>').input_ids
)

# 动态提升状态边界的惩罚权重
special_mask = torch.isin(Y.view(-1), torch.tensor(think_boundary_ids).to(args.device))
loss_mask_flat = loss_mask.view(-1).clone()
loss_mask_flat[special_mask] = 10.0  # 状态切换必须严丝合缝，出错重罚！
```
